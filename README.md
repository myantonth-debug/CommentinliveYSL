# Anton × Saint Laurent — Comment Randomizer

เว็บสุ่มคอมเมนต์สำหรับไลฟ์ Saint Laurent (สุ่มไม่ซ้ำจนครบรอบ + คัดลอกอัตโนมัติ)

## อัพขึ้น GitHub Pages
1. สร้าง repo ใหม่ แล้วอัพโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `images`)
2. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save
3. รอสักครู่ จะได้ลิงก์ `https://<username>.github.io/<repo>/`

## เพิ่มคอมเมนต์
แก้ไฟล์ `comments.js` — เพิ่มบรรทัดในหมวดที่ต้องการ (มีเครื่องหมาย `" "` และจุลภาคท้ายบรรทัด)

## เปลี่ยนรูป
วางรูปใน `images/` ตั้งชื่อ `01.jpg`–`06.jpg` หรือแก้รายชื่อใน `app.js` (`PHOTOS`)
